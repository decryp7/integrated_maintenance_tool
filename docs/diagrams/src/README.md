# Diagram sources

The `.drawio` files and `debrief-overview.svg` one folder up are generated by these scripts from the Paddock diagram kit
(`paddock/diagrams/tools`, expected as a sibling checkout next to `debrief`). The `.drawio` files stay editable in draw.io;
re-running a script overwrites its diagrams.

| Script | Diagrams |
|---|---|
| `c4.mjs` | C4 context and the three container diagrams (workbench, AI and research, command line) |
| `c43.mjs` | C4 components: engine (ingest, query, analysis, sharing), UI (frame, investigating, tools), research browser |
| `cls.mjs` | Classes: domain (store, events, profile, queries) and plugin API (plugin side, registry, out of process) |
| `proto.mjs` | The store port table and wire |
| `act.mjs` | Activities: ingest (two parts) and video sources |
| `seq.mjs` | Sequences: Moment, open a folder (two), plugins (two), queries (three), watched folders, command line |
| `state.mjs` | States: live tail (two), Performance Monitor, project, session, one watched file |
| `ucs.mjs` | Use cases (four) |
| `deploy.mjs` | Deployment: workstation, monitored server, build and downloads |
| `overview.mjs` | `debrief-overview.svg` |
| `common.mjs` | Shared helpers (grid layout, groups, realisation arrows, sequence scripts) |

```sh
docs/diagrams/src/generate.sh      # regenerate every .drawio and the overview SVG
scripts/export-diagrams.sh         # then export SVG (and the git-ignored 2x PNGs); draw.io desktop, one export at a time
```

Each script sets the product name "Debrief" in titles and footers and keeps code identifiers (`imt-core` and so on) as they are in
the code. The footer date is `DATE` in `common.mjs`.
